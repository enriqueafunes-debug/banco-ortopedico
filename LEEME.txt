BANCO ORTOPÉDICO - PRUEBA CLUB v11

Proyecto Android listo para compilar con el mismo GitHub Actions que ya funcionó.

IMPORTANTE PARA ACTUALIZAR EL REPOSITORIO:
No arrastre la carpeta APP desde dentro del ZIP abierto.
Primero use "Extraer todo" en Windows.
Luego suba/reemplace respetando estas rutas:

app/build.gradle.kts
app/src/main/AndroidManifest.xml
app/src/main/assets/app.js
app/src/main/assets/index.html
app/src/main/assets/styles.css
app/src/main/java/org/rotary/bancoortopedico/MainActivity.java
app/src/main/res/drawable/ic_launcher.xml
app/src/main/res/values/strings.xml
app/src/main/res/values/styles.xml

El archivo raíz build.gradle.kts debe quedar así:
plugins {
    id("com.android.application") version "8.7.3" apply false
}

No es necesario modificar .github/workflows/build-apk.yml si el workflow actual ya compila.

Nota sobre aceptación remota:
Esta versión abre WhatsApp real con los reportes y recibos. Como la app funciona localmente y no tiene servidor público, el cliente confirma por WhatsApp y el encargado registra la aceptación desde la app. Para que el cliente pulse un link web de aceptación desde otro teléfono hace falta agregar un backend/servicio web publicado.
